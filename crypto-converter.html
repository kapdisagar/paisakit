How the value is calculated

Simple multiplication of your coin amount with the coin's current reference price:

Value = Amount × Price(coin, currency)

Example: 0.5 BTC at a reference price of ₹98,00,000 per BTC = 0.5 × 98,00,000 = ₹49,00,000. Actual prices load live from the API — crypto moves fast, so the number you see now can change within minutes.

FAQ

Which price is shown here?

An aggregated mid-market reference price from CoinGecko, averaged across major exchanges. It is a fair reference point — no exchange will give you exactly this rate. Exchanges add a spread and trading fee, and in India every sale attracts 1% TDS on top.

Crypto gains par India mein tax?

As per current Indian tax rules, virtual digital asset gains are taxed at a flat 30% (plus applicable cess), losses cannot be set off against other income, and 1% TDS applies on transfers above threshold limits. Tax rules change — confirm with a CA before filing.

How fresh are the prices?

Your browser caches prices for 5 minutes so the page loads fast and saves API quota. Crypto is volatile — treat the shown value as a reference, not a tradable quote.

Is this investment advice?

No. This is an information tool only. Crypto assets are volatile and risky; never invest money you cannot afford to lose. Not financial advice.
