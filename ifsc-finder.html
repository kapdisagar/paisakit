How an IFSC code is structured

Every IFSC code has three fixed parts, assigned by the Reserve Bank of India:

IFSC = BANK (4 letters) + 0 + BRANCH (6 characters)
HDFC 0 000001 → HDFC Bank, branch code 000001

The first 4 letters identify the bank (same for every branch), the 5th character is always 0 (reserved by RBI for future use), and the last 6 characters identify the exact branch.

FAQ

What is an IFSC code?

Indian Financial System Code — an 11-character code the RBI assigns to every bank branch. It uniquely identifies the branch in electronic payments like NEFT, RTGS and IMPS.

Where do I find my IFSC?

On every cheque leaf (top-left corner, next to the cheque number), on your passbook's first page, and in your bank's website or app. Example format: HDFC0000001.

Is the IFSC the same for all branches of a bank?

No. The first 4 letters are the same for every branch of a bank, but the last 6 characters are unique to each branch. Always use the exact branch's code for NEFT/RTGS.

Do I need an IFSC for UPI?

Not usually — UPI works with UPI IDs and mobile numbers. You only need the IFSC when adding a payee through the account number + IFSC route, or for NEFT/RTGS/IMPS bank transfers.
