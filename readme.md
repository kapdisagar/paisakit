# PaisaKit 💸

Free, fast, privacy-first finance calculators for India. Every tool runs 100% in the browser — no backend, no tracking of user input.

**Live:** https://kapdisagar.github.io/paisakit/

## Tools
- SIP Calculator (with yearly step-up)
- EMI Calculator
- GST Calculator (add/remove, CGST/SGST split)
- FD Calculator (quarterly compounding)
- PPF Calculator (year-by-year table)
- Age Calculator

## Stack
Plain HTML/CSS/JS. Zero dependencies. Static hosting (GitHub Pages).

## Adding a tool
1. Copy an existing tool page as template.
2. Add the card + results + FAQ + JSON-LD.
3. Update `index.html`, `sitemap.xml`.
4. Push — Pages auto-deploys.
